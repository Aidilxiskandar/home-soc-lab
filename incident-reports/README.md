# Incident Reports

SOC-style reports written from lab alerts, one per file.

```markdown
# IR-NNN: <Title>

| Field | Value |
|---|---|
| Date detected | |
| Severity | Low / Medium / High / Critical |
| Affected asset | |
| ATT&CK technique | |
| Status | Open / Contained / Closed |

## Summary
Two or three sentences a manager could read.

## Timeline
| Time | Event |
|---|---|

## Analysis
Evidence, alerts, and how the conclusion was reached.

## Containment and remediation
What was done and what should be done.

## Lessons learned
Detection gaps, tuning, and process improvements.
```
