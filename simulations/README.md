# Attack Simulations

One file per simulation, named `NN-short-name.md`, using the template below.

```markdown
# NN: <Simulation name>

- **ATT&CK technique:** <ID and name>
- **Target:** <lab machine>
- **Date run:** YYYY-MM-DD

## Goal
What attacker behaviour this copies, and why it matters.

## Steps
Exact commands run (lab only).

## Expected evidence
Which logs or events should show it.

## Result
Did Wazuh alert? Rule ID, alert level, screenshot.

## Linked detection
`../detections/NN-short-name.md`
```
